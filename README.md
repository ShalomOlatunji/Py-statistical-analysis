This is my Module 3 assignment on data analysis with Python and Pandas. I used the Iris dataset from scikit-learn, which contains measurements of 150 flowers.

The code is in iris_assignment.py.

What I did

Checked the first few rows, column types, and summary statistics.

Calculated the mean, median, mode, and sample standard deviation for each measurement.

Used correlation to explore relationships between the measurements.

Main finding

Petal length and petal width have a strong positive correlation of 0.963. In this dataset, flowers with longer petals tend to have wider petals.

How to run

Open a terminal in the folder containing iris_assignment.py and run:

python -m pip install pandas scikit-learn
python iris_assignment.py

The results will appear in the terminal.
